Continuous-time LiDAR Odometry with
Corresopndence-free Locally Optimized MSAC

IEEE Robotics and Automation Letters (RA-L) 2026

Abstract

This work presents a continuous-time LiDAR odometry method with GPU-accelerated locally optimized MSAC (LO-MSAC) that can deal with the sensitivity to initialization of continuous-time ICP caused by motion distortion. Point clouds acquired by a LiDAR with a sweeping mechanism or a rolling-shutter mechanism can be severely distorted under aggressive motion during scanning. Conventional rigid point cloud registration methods require prior deskewing to obtain an accurate motion estimate, whereas continuous-time ICP jointly optimizes the trajectory during scanning while enforcing spatial and temporal consistency. In practice, however, continuous-time ICP is sensitive to the initial guess and its optimization can be unstable. To obtain a reliable initialization, the proposed method performs LO-MSAC with a large number of hypotheses (e.g., 50,000), which runs continuous-time ICP optimization without explicit correspondence estimation for each pose hypothesis by leveraging GPU parallelism. Experiments demonstrate that the proposed method robustly estimates the sensor trajectory even under aggressive motion in real-time, using only LiDAR measurements. We release the code of the proposed method and in-house dataset upon acceptance of the paper.

System Overview

Given $N$ inputs comprising RGB images, LiDAR point clouds, and optional geometric cues, LiV3R projects each modality into a shared latent space using modality-specific encoders. Each LiDAR scan is preprocessed into a single-channel intensity image together with ray directions, depth, and a sparsity mask; these signals are stacked and jointly fed into the LiDAR encoder.
